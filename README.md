# CSC584 Individual Assignment 1 - Personal Profile Web Application

## Project Description
A simple Personal Profile Web Application built as part of the CSC584 course assignment requirements. It collects user profile information through an HTML form, processes it with a Java Servlet using an HTTP POST request, and displays the submitted data cleanly on a JSP page.

## Technologies Used
- HTML5 and CSS3
- Java Servlet
- JavaServer Pages (JSP)
- NetBeans 8.2
- GlassFish Server 4.1.1
- JDK 8

## How to Run the Application
1. Open NetBeans IDE 8.2.
2. Ensure GlassFish Server 4.1.1 is configured under Tools -> Servers.
3. Import or open this project folder in NetBeans.
4. Right-click the project name and select **Clean and Build**.
5. Right-click the project name and select **Run** (or press F6).
6. Open your browser and navigate to `http://localhost:8080/CSC584-Individual-Assignment-1/index.html`.
